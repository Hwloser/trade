## 二、各阶段详细计划

### 阶段 0:美股技术面基线(约一周,AI 全程执行)

**回答的问题**:在 A 股上"真实但太弱"的技术因子信号,在美股上是什么样?

**做法**:
1. 取标普 500 成分股 5 年日线(Stooq 免费批量下载,备选 yfinance)。
2. 直接跑现有的 `debug/eval_baseline/`(11 因子 RankIC)和 `debug/lgbm_walkforward/`(LightGBM walk-forward,及格线原样保留:OOS RankIC ≥ 0.02 且 t ≥ 2 且扣费后多空为正)。
3. 有条件的话用带退市股的成分股历史名单,消掉 A 股实验里承认过的幸存者偏差。

**你要做的**:等一天,读结论。

**预期与解读**:文献上美股大盘股技术面信号比 A 股更弱(市场更有效)。如果结果同样是"弱到不可交易"——**这不是坏消息**,它确认了美股线的重心必须放在事件驱动(阶段 1~3),和那份分析文档的判断一致。

### 阶段 1:数据层改造(1~2 周,AI 写码,你 review PR + 决定合并)

**1a. 美股 K 线 provider**
- 新增 `StooqKlineProvider` / `YfinanceKlineProvider`,实现现有 `KlineProvider` 协议。
- 把 A 股专用的符号逻辑(`600000.SH`、`ensure_a_share_symbol`)抽象成 per-market 策略,`AAPL` 直接过。
- 从第一天就带上:socket 超时(A 股线 16 小时挂死的教训)、双源交叉校验(抄 BTC 线的 assurance 模板)。

**1b. SEC EDGAR 接入(全计划最有价值的一步)**
- **8-K(重大事件公告)**:美国证监会规定上市公司重大事件 4 个工作日内必须申报,且**自带结构化的事件类型编号**(Item 1.01=签重大合同、Item 5.02=高管变动、Item 2.02=业绩发布……)。A 股线上我们费劲让 LLM 从新闻里猜 `event_type`,EDGAR 直接把标准答案给你。免费、官方、无限量、从日本实测可达(已验证 http 200)。
- **Form 4(内部人交易)**:CEO/CFO 买卖自家股票的申报,方向性极强的证据源。
- 接法:每日轮询 EDGAR 全文检索 API → 落 Bronze 层(复用现有 sentiment 管道的分层结构)→ 8-K Item 编号直接映射 `event_type`,LLM 只负责读正文打幅度分和摘要。
- **LLM 工作量反而变小**:事件类型不用猜了,Qwen 只做它对照实验里表现好的部分(情绪/幅度),薄弱的部分(事件分类)被官方数据替代。

**1c. 英文新闻源**
- 现有 feed 里 WSJ、Fed、ECB 等英文源直接保留(它们对 A 股没用,对美股正好有用——原来的"废料"变成了原料)。
- GDELT 通道代码已存在,激活。
- 追加:各公司 IR 页 RSS、Nasdaq/GlobeNewswire/PRNewswire 的 press release feed(免费)。

**你要做的**:看两三个 PR 的人话说明,点合并;顺手把之前建议的券商开户确认掉。

### 阶段 2:美股信息哨兵上线(2~4 周)

- dagu 新增 `us-daily` DAG:日本时间每天早上 6:30(美股收盘后半小时)跑 K 线同步 → EDGAR 拉取 → Qwen 富化 → 信念更新 → 输出报告。
- 报告形态(哨兵,不是荐股):
  - 你自选关注列表里的公司,昨夜发生了什么(8-K 事件、内部人买卖、大新闻);
  - 异动榜:昨夜事件密度/情绪最极端的股票;
  - 风险提示:未确认的异常(抄 BTC 线的 UNCONFIRMED_PRICE_ANOMALY 思路)。
- EBRT 链路(信念更新→推荐)同步在美股符号上空转积累记录,但**输出仅供观察,不作为行动依据**——直到阶段 3 验证过。

**你要做的**:`make deploy` 部署 DAG(你自己动手,我不碰你的 dagu);每天早上花 3 分钟看报告,觉得没用就告诉我哪里没用——这是唯一能把报告调好的反馈回路。

### 阶段 3:第一个可验证策略——财报事件 PEAD(3~6 个月)

**为什么选 PEAD(盈余公告后漂移)**:财报超预期后股价倾向于继续漂移数周,是美股文献里最持久的异象之一;事件定义 100% 客观(财报日期和 EPS 是公开硬数据),不依赖 LLM 判断,最不容易自欺;且历史财报可回溯,**不用等数据积累就能先回测**——这是它和新闻情绪路线的本质区别。

**做法**(照抄 LightGBM 实验的纪律):
1. 事先注册及格线(写死在代码里再跑);
2. 用历史财报数据回测:财报超预期 → 持有 N 天的费后收益、与随机对照/动量对照比;
3. 及格 → 接入哨兵报告作为"高置信事件"类别,再考虑真金白银的小仓位;不及格 → 写结论存档,策略线止损,哨兵照常运行。

**你要做的**:读结论,做那个最重要的决定——投不投钱。**任何时候不及格的东西不投钱。**

## 三、你的"金融词汇最小生存包"

计划里绕不开的词,每个一句人话:

| 词 | 人话 |
|---|---|
| **IC / RankIC** | 预测排名和实际涨跌排名的相关度。0 = 瞎猜,0.03 = 业界"弱但真实",0.1 = 非常强 |
| **walk-forward** | 只用过去数据训练、在"未来"上考试,滚动往前推——防止用答案复习 |
| **幸存者偏差** | 只统计今天还活着的股票,死掉的不算,结果必然偏乐观 |
| **8-K** | 美国上市公司的"重大事件强制申报表",带官方事件分类编号 |
| **Form 4** | 高管买卖自家股票的申报——内部人用真金白银投的票 |
| **PEAD** | 财报超预期后,股价往往还会朝同方向漂移几周,不会一步到位 |
| **多空价差** | 买入模型最看好的、卖空最看衰的,两边收益之差——信号能否变成钱的最直接检验 |
| **及格线事先注册** | 跑实验之前就把"多少算通过"写死,防止事后挑好看的数字骗自己 |

## 四、风险与止损点(事先说清)

1. **阶段 0 大概率"不及格"**——预期内,不影响路线(重心本来就在事件驱动)。
2. **阶段 3 的 PEAD 也可能不及格**(该异象近年有减弱的文献争议)。止损协议:不及格就停策略线,哨兵作为免费的信息工具继续活着——它本身已经有用。
3. **最大的隐性风险是你的时间**:如果早上 3 分钟看报告都坚持不了两周,说明哨兵形态不对,应该先改产品形态而不是继续堆技术。
4. **本计划不含自动交易**,与 A+B 路线的约定一致。任何下单永远由你手动执行。
